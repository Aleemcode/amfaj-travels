# AMFAJ Travels and Tours - Website Planning Blueprint

## Website Mission

Build a trust-first website that converts social media, WhatsApp Status, referrals, and Meta/TikTok traffic into qualified WhatsApp leads for Umrah and later Hajj.

The first website should not behave like a large travel marketplace. It should be a clear, dignified, lead-capture platform that helps a serious visitor understand AMFAJ, trust the promise, and take the next step.

## Primary Goal

Convert interested visitors into qualified WhatsApp leads.

Primary CTA:

Start Registration.

Secondary CTA:

Browse Packages.

## Audience

Primary:

- Muslims in Nigeria who love the Sunnah.
- Prospective Umrah pilgrims.
- Families and sponsors planning for parents, spouses, or relatives.
- People who want clear guidance, financial integrity, and zero hidden fees.

Secondary:

- Future Hajj prospects.
- Islamic learning communities and masajid contacts.
- People who are not ready to travel yet but want to prepare.

## Core Positioning

AMFAJ Travels and Tours helps Muslims in Nigeria prepare for Hajj and Umrah with honesty, personalized hospitality, financial integrity, zero hidden fees, and guidance upon the Qur'an and Sunnah according to the understanding of the pious predecessors.

## Technical Recommendation

MVP stack options:

Option A: Simple static website.

- Best if speed and low maintenance matter most.
- Can be built with HTML/CSS or a lightweight framework.
- Easy to host on Vercel or Netlify.

Option B: WordPress.

- Best if non-technical team members need to edit pages often.
- More maintenance and security work.

Option C: Webflow/Framer.

- Best if design speed and visual editing matter.
- Less code control but fast for marketing pages.

Recommended first path:

Static marketing website with clean code, WhatsApp CTAs, basic analytics, and Google Sheets/form integration later.

## Claim-Safety Rules

- Use only the package prices, inclusions, travel windows, and departure locations saved in `gemini.md`.
- Do not add extra inclusions unless AMFAJ provides them.
- Do not imply any visa outcome guarantee beyond listing Umrah visa as an inclusion.
- Do not imply worship acceptance is guaranteed.
- Do not present religious statements casually.
- Review all claims before publication.
